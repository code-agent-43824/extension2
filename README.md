# КриптоПро через Рутокен

Расширение браузера: сайты, написанные под КриптоПро ЭЦП Browser plug-in и КриптоПро CSP, подписывают через
Рутокен Плагин и Рутокен ЭЦП 2.0 или 3.0 — без КриптоПро CSP. Расширение выключено на всех сайтах, пока пользователь
не включит его на нужном.

- **Установить** — архив `cryptopro-via-rutoken-<версия>.zip` со страницы
  [Releases](https://github.com/code-agent-43824/extension2/releases): внутри сборки для Chrome и Firefox и
  `README.txt` с установкой.
- **Проверить сборку вручную** — [`docs/MANUAL-CHECK.md`](docs/MANUAL-CHECK.md).
- **Что работает и что проверено** — [`docs/STATUS.md`](docs/STATUS.md).
- **Как устроено** — [`docs/ANALYSIS.md`](docs/ANALYSIS.md); этапы — [`docs/ROADMAP.md`](docs/ROADMAP.md).
- **Разработка** — команды и карта кода в [`CLAUDE.md`](CLAUDE.md), правила — [`AGENTS.md`](AGENTS.md).
