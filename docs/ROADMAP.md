# ROADMAP — куда идёт проект

## Продукт

Расширение для Chrome. На сайтах, написанных под **КриптоПро ЭЦП Browser plug-in + КриптоПро CSP**, оно ведёт себя
как эта связка, а настоящую работу делает связка **Адаптер Рутокен Плагин → Рутокен Плагин → Рутокен ЭЦП 2.0/3.0**.
КриптоПро у пользователя не установлен.

Как это устроено и почему именно так — [`ANALYSIS.md`](ANALYSIS.md). Коротко: наш скрипт в мире страницы
определяет `window.cadesplugin` раньше скрипта сайта, эмулирует объекты CAdESCOM и вызывает Рутокен Плагин через
объект, который адаптер Рутокена сам кладёт на страницу.

Три свойства, ради которых всё делается:

1. **Сайт не замечает подмены** — те же объекты, свойства, форматы строк и коды ошибок, что у КриптоПро.
2. **Ключ не покидает токен** — подписывает Рутокен, пользователь видит PIN-окно и подтверждение.
3. **Всё проверяется без железа** — стенд с настоящим Рутокен Плагином и fake Рутокеном (SoftHSMv2), см. раздел 8
   `ANALYSIS.md`.

## Этапы

| # | Этап | Результат этапа |
| --- | --- | --- |
| 1 | Тестовый стенд без железа | Автотест в Chromium: страница-пробник через настоящий Адаптер и Рутокен Плагин находит fake Рутокен, его сертификат и подписывает |
| 2 | Каркас расширения и «загрузка плагина» | Демо-страница `cades_bes_sample.html` на стенде показывает «Плагин загружен» и сведения о «криптопровайдере» |
| 3 | Сертификаты | Демо-страница показывает сертификат с токена и его карточку |
| 4 | Подпись CAdES-BES | Демо-страница подписывает (присоединённая и отсоединённая), подпись проходит независимую проверку; окно PIN и подтверждение |
| 5 | Проверка владельцем на живом Рутокене | Сборка расширения, инструкция установки, ручной прогон демо-страницы в настоящем Chrome |
| 6 | Остальное API по мере целевых сайтов | `HashedData`/`SignHash`, `CoSignCades`, `VerifyCades`, XML-подпись, шифрование, CAdES-T и X Long, выпуск сертификата — по списку сайтов владельца |
| 7 | Другие браузеры | Firefox, затем остальные — по решению владельца |

Этапы предложены агентом 2026-09-23 по ответам владельца: первая цель — демо-страница, пока только Chrome, целевые
ключи — PKCS#11. Состав этапов 6–7 будет уточняться. Где проект сейчас и подтверждена ли карта —
[`STATUS.md`](STATUS.md).
