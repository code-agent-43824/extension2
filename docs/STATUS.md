## Известные проблемы

- Форматы `SubjectName`, `IssuerName`, дат и отпечатка не сверены с настоящим КриптоПро (`JOURNAL.md`, этап 3).
- `HasPrivateKey()` всегда `true` для сертификатов пользователя, `IsValid()` и `CheckCertificate` проверяют только
  сроки.
- Выпуск сертификата: сертификаты УЦ из ответа не ставятся; «понятное имя» сертификата не сохраняется; ключ
  «подпись и обмен» (выбор страницы по умолчанию) экспортные Рутокен ЭЦП 3.0 не создают — тогда нужен «ключ
  подписи»; эмулированы только объекты, которые вызывает certsrv.
- Сайты не видят хранилища корневых (`Root`): проверка условий lkip2.nalog.ru (шаг checkCA) не находит корни
  ГУЦ и Минцифры, хотя они есть в хранилище на странице настроек. Сам вход ИП — на lkipgost2.nalog.ru, только по ГОСТ TLS, из Chrome недоступен.
- В подпись не попадают атрибуты сайта (время подписи ставит Рутокен Плагин, «имя документа» теряется) и цепочка
  сертификатов; CAdES-T, X Long и проверка подписи не поддерживаются (этап 6).
