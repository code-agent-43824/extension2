## Что работает

- Тестовый стенд без железа (`npm run stand`): настоящий Рутокен Плагин 4.12.3.0 и Адаптер 1.1.0.0 в headless
  Chromium, fake Рутокен SoftHSMv2 `v2.7.0-portable.42`, ключ ГОСТ 2012/256 и сертификат тестового УЦ на токене.
- Дымовой тест стенда (`npm run test:stand`): подпись CAdES-BES присоединённая и отсоединённая, проверка с
  цепочкой. Зелёный локально и в CI (GitHub Actions `ci`, прогоны 2026-09-23, стенд собирается на чистом
  раннере с нуля).
- Расширение (`npm run build` → `dist/extension/`): определяет `window.cadesplugin`, загружает Рутокен Плагин
  через адаптер, эмулирует `CAdESCOM.About`. Демо-страница КриптоПро на стенде показывает «Плагин загружен» и
  «Криптопровайдер загружен», список сертификатов с токена и карточку выбранного сертификата
  (`tests/stand/demo-page.spec.ts`). Подписи пока нет.

## Известные проблемы

- Форматы `SubjectName`, `IssuerName`, дат и отпечатка не сверены с настоящим КриптоПро (`JOURNAL.md`, этап 3).
