# Ручная проверка на настоящем Chrome и Рутокене

Для этапа 5 ([`ROADMAP.md`](ROADMAP.md)) и для любой проверки новой сборки руками. Что уже проверено автоматически
и что нет — [`STATUS.md`](STATUS.md).

## Что понадобится

- Chrome (версия не ниже `minimum_chrome_version` в `src/manifest.json`). Лучше **отдельный профиль Chrome без
  расширения КриптоПро**: если оба расширения включены на одном сайте, сайт увидит только одно из них.
- Рутокен ЭЦП 2.0 или 3.0 с ключом ГОСТ Р 34.10-2012 **256 бит** и сертификатом к нему, записанными как объекты
  PKCS#11 (так их создаёт Рутокен Плагин). Контейнеры КриптоПро на токене расширению не видны — решение в
  `CLAUDE.md`. Проверяльщик подписей `tests/tools/verify_cms.py` пока умеет только 256 бит.
- Для сверки полей — машина или профиль с настоящим КриптоПро CSP и КриптоПро ЭЦП Browser plug-in, куда вставлен
  тот же Рутокен с тем же сертификатом в хранилище «Личное».

## Установка

1. Драйверы Рутокен (для Windows — <https://www.rutoken.ru/support/download/windows/>).
2. Рутокен Плагин — <https://www.rutoken.ru/support/download/rutoken-plugin/>.
3. Расширение «Адаптер Рутокен Плагин» из Chrome Web Store —
   <https://chromewebstore.google.com/detail/ohedcglhbbfdgaogjhcclacoccbagkjg>.
4. Наше расширение: распаковать архив `cryptopro-via-rutoken-<версия>.zip` (`npm run package` или артефакт
   `cryptopro-via-rutoken` прогона CI), открыть `chrome://extensions`, включить «Режим разработчика», нажать
   «Загрузить распакованное расширение» и выбрать папку `cryptopro-via-rutoken-<версия>` из архива.

## Ключ и сертификат на токене

Если на токене ещё нет ключа ГОСТ с сертификатом в PKCS#11, их можно сделать на демо-сайте Рутокена
<https://ra.rutoken.ru/> («Возможности Рутокен Плагин»): «Создание ключей» с алгоритмом ГОСТ Р 34.10-2012
256 бит, затем «Создать заявку на тестовый сертификат» и «Добавить тестовый сертификат». Разделы названы по тексту
сайта; сам этот путь агент не проходил — устройства у него нет. Для проверки подписи понадобится ещё сертификат
УЦ, который выдал сертификат пользователя (файл `.cer` или `.pem`).

## Чек-лист

Отмечайте, что увидели; где не совпало — снимок экрана и текст.

1. Открыть <https://www.cryptopro.ru/sites/default/files/products/cades/demopage/cades_bes_sample.html>. Сайт ещё
   не включён: страница не находит расширения (на стенде она пишет «Расширение не загружено» и «Плагин:
   ожидание загрузки расширения»).
2. Нажать кнопку расширения «КриптоПро через Рутокен». В окне адрес `https://www.cryptopro.ru` и переключатель
   «Включено на этом сайте». Включить: Chrome спрашивает доступ к сайту — разрешить. Вкладка перезагружается.
3. Страница пишет «Расширение загружено», «Плагин загружен», «Криптопровайдер загружен», версии 2.0.15000 и
   5.0.13000, криптопровайдер «Rutoken Plugin …».
4. В списке «Выберите сертификат» — сертификат с токена. Выбрать его: карточка заполнена (владелец, издатель,
   даты, отпечаток, алгоритм, статус).
5. «Подписать». Появляется окно «Подпись через Рутокен»: сайт `https://www.cryptopro.ru`, «11 байт, присоединённая
   подпись», владелец и издатель сертификата. Ввести неверный PIN — окно просит ещё раз (попытки PIN
   ограничены, одной ошибки достаточно). Ввести верный — «Подпись сформирована успешно:» и подпись ниже.
   **Скопировать подпись в файл** `attached.txt`.
6. Отметить «Отделенная подпись» и «Проверять подписанта», «Подписать», верный PIN. **Скопировать подпись** в
   `detached.txt`.
7. «Подписать» и «Отмена» в окне PIN: страница пишет «Возникла ошибка:» и «… отменено пользователем.
   (0x8010006E)».
8. Страница настроек расширения («Все включённые сайты» в окне кнопки): в списке `https://www.cryptopro.ru`.
   «Выключить», перезагрузить демо-страницу — снова как в пункте 1.

Прислать: `attached.txt`, `detached.txt`, сертификат УЦ, заметки по пунктам.

## Сверка полей с КриптоПро

1. На машине с настоящим КриптоПро открыть демо-страницу (наше расширение на этом сайте выключено или не
   установлено), дождаться «Плагин загружен».
2. Открыть DevTools (F12), вкладку Console. Chrome может попросить сначала ввести `allow pasting`.
3. Вставить весь текст [`tools/dump-fields.js`](../tools/dump-fields.js) и нажать Enter. Результат — JSON — уже
   скопирован в буфер обмена; сохранить в `cryptopro.json`. Скрипт ничего не подписывает и PIN не спрашивает.
4. То же самое в Chrome с нашим расширением, включённым на демо-странице; сохранить в `ours.json`.
5. Сравнение: `node scripts/compare-fields.ts cryptopro.json ours.json` — печатает каждое различие. Или просто
   прислать оба файла.

В обоих файлах есть `userAgent`, серийный номер и отпечаток сертификата и поля его субъекта — это данные
сертификата; если они не для чужих глаз, пришлите только результат сравнения.
