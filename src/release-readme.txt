КриптоПро через Рутокен {{version}}
================================

Расширение браузера: сайты, рассчитанные на КриптоПро ЭЦП Browser plug-in, подписывают через Рутокен Плагин
и Рутокен ЭЦП 2.0 или 3.0 — без КриптоПро CSP.

Что в этой папке
----------------

  chrome     — расширение для Google Chrome (вся папка)
  firefox    — расширение для Mozilla Firefox (файл .xpi)
  README.txt — эта инструкция


Сначала, для любого браузера
----------------------------

1. Драйверы Рутокен (только для Windows): https://www.rutoken.ru/support/download/windows/
2. Рутокен Плагин: https://www.rutoken.ru/support/download/rutoken-plugin/


Google Chrome (версия {{chrome}} или новее)
-------------------------------------------

3. Расширение «Адаптер Рутокен Плагин»:
   https://chromewebstore.google.com/detail/ohedcglhbbfdgaogjhcclacoccbagkjg
4. Положите эту папку туда, где она останется: Chrome берёт расширение из папки chrome при каждом запуске,
   удалять или переносить её потом нельзя.
5. Откройте адрес chrome://extensions и включите «Режим разработчика» (переключатель справа вверху).
6. Нажмите «Загрузить распакованное расширение» и выберите папку chrome.
7. Закрепите значок «КриптоПро через Рутокен» на панели: кнопка-пазл справа от адресной строки.


Mozilla Firefox (версия {{firefox}} или новее)
----------------------------------------------

3. Дополнение «Адаптер Рутокен Плагин»: https://addons.mozilla.org/firefox/addon/adapter-rutoken-plugin/
4. Наше расширение пока не подписано Mozilla, поэтому ставится одним из двух способов.

   Обычный Firefox — до его закрытия, после перезапуска шаг нужно повторить:
   откройте адрес about:debugging, слева «Этот Firefox», нажмите «Загрузить временное дополнение…» и выберите
   файл .xpi из папки firefox.

   Firefox ESR, Developer Edition или Nightly — насовсем:
   откройте about:config, найдите xpinstall.signatures.required и поставьте false; затем откройте about:addons,
   нажмите шестерёнку, «Установить дополнение из файла…» и выберите файл .xpi из папки firefox.


Как включить на сайте
---------------------

Расширение выключено на всех сайтах, пока вы не включите его сами. Откройте сайт, нажмите значок расширения и
отметьте «Включено на этом сайте». Браузер спросит разрешение на доступ к сайту — разрешите; страница
перезагрузится. Список включённых сайтов — по ссылке «Настройки» в том же окне.

PIN-код Рутокена расширение спрашивает в своём окне на странице, перед каждой подписью. Галочка «Запомнить PIN-код
до закрытия страницы» оставляет для следующих подписей на этой странице только кнопку подтверждения.

Как проверить эту версию вручную: https://github.com/code-agent-43824/extension2/blob/v{{version}}/docs/MANUAL-CHECK.md
